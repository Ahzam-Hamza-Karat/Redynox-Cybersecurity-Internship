# Redynox Cybersecurity Internship

This repository documents the practical tasks completed during the **Redynox Cybersecurity Internship**.

The internship focused on hands-on cybersecurity implementation using real-world tools such as **Wireshark, OWASP ZAP, and WebGoat**, covering both network security and web application security testing.

---

## 📌 Internship Overview

- **Organization:** Redynox
- **Role:** Cybersecurity Intern
- **Duration:** June 6, 2025 – July 5, 2025
- **Mode:** Remote
- **Focus Area:** Network Security & Web Application Security
